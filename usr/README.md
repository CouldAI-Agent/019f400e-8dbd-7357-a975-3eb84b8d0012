# Logistics Dashboard

A Flutter application featuring a polished dashboard for managing vehicle packages and driver hiring, based on a provided design mockup.

## Features

*   **Vehicle Packages:** Clean grid view displaying available vehicles, their features (seats, AC), and pricing details.
*   **Driver Hiring:** Section dedicated to hiring drivers for specific time slots.
*   **Modern UI:** A clean, blue and white themed interface with consistent card designs, typography, and iconography.
*   **Responsive Layout:** Adapts to different screen sizes, providing a great experience on mobile and desktop platforms.

## Tech Stack

*   Flutter
*   Dart

## Setup and Run

1.  Ensure you have Flutter installed on your system.
2.  Run `flutter pub get` to fetch dependencies.
3.  Run `flutter run` to launch the application.
